# TalentStage Brand Requirements

## Visual Identity

- **Feel:** Futuristic, premium, AI-powered creator universe
- **Avoid:** Generic Bootstrap, flat corporate dashboards, school-project aesthetics

## Colors

| Token | Hex | Usage |
|-------|-----|-------|
| Primary purple | `#7C3AED` | CTAs, accents |
| Neon blue | `#00D4FF` | Links, highlights |
| Accent pink | `#FF4D9D` | Badges, emphasis |
| Background | Deep navy `#0a0e1a` | Page base |

## Typography

- **Font:** Poppins (Google Fonts)
- **Style:** Bold headings, high contrast body text

## UI Patterns

- Glassmorphism cards (`backdrop-filter`, semi-transparent borders)
- Neon gradient text on heroes
- Soft glow hovers on interactive cards
- Verified badges (green) and AI badges (purple)

## Voice

- Creator-focused, competitive, empowering
- No lorem ipsum — use realistic freelancer/project copy
